## 읽는 법

파일 문법은 [01](01-game-structure.md)의 "데이터 파일 형식"에 있다. 데이터 줄은 두 가지다.

| 모양 | 예 | 이 문서에서 |
|---|---|---|
| 이름으로 시작하는 줄 | `gdpc 51203` · `initialfunds:   2` · `primerate, 0.035` | 키 섹션 — 키마다 한 행 |
| 쉼표 행 | `2413, "Leopard 2A7+", 2, 1746, …` | 표 섹션 — 열마다 한 행 |

캐시 하나를 여러 시나리오가 함께 쓴다: World 2030 계열 시나리오 아홉 개가 모두 `W2030` 을 가리킨다. **[확인: 시나리오 파일]**

위키가 말하는 것: **[위키]**

- 원본 데이터(`*.UNIT`, `*.CVP` 등 캐시에 구워지는 것)를 고치면 그 지도의 캐시를 다시 만들어야 게임에 보인다.
- 로비 설정의 "Force Recache for Modding" 을 켜면 게임이 캐시를 다시 만들어 제자리(`Cache\`)에 같은 이름으로 둔다. 캐시 파일을 지워도 다시 만든다. 부대가 든 지도는 오래 걸린다 — 시험할 때는 시나리오의 `*.OOB` 줄을 주석으로 막으면 5분 안쪽이라고 한다.
- `&&GMC` 의 `ignorecache: 1` 은 있는 캐시를 무시하고 다시 만들게 한다.
- **캐시 뒤에 읽는 자료는 캐시를 다시 만들지 않아도 된다.** 시나리오 파일 끝에 `&&CVP <지역 번호>` 블록을 덧붙이면 그 지역의 값을 덮어쓴다(예: `&&CVP 1106` 다음 줄에 `techlevel 104`). `&&UNITS` 행도 같은 방식으로 덧붙일 수 있다.

게임에서 확인한 것 (2026-10-06, build `21347933`, 2030 - 세계 · 독일. 값 하나만 바꾼 시험 모드를 설치해 새 게임에서 봤다): **[확인]**

| 고친 것 | 캐시 재생성 없이 | 재생성 뒤 |
|---|---|---|
| `Maps\DATA\DEFAULT.UNIT` 의 장비 값 (`0x02` 단계) | 반영되지 않는다 | 반영된다. Leopard 2A7+ 의 비용 6 → 66 이 건설 비용 $579 M → $6,373 M |
| `Maps\W2030.CVP` 의 지역 값 (`0x01` 단계) | 반영되지 않는다 | 반영된다. 독일의 `gdpc` 51203 → 99999 가 1인당 GDP $50,857 → $99,257. 국가 부채도 $2.70 T → $5.27 T 로 함께 는다 |
| 시나리오 파일의 `&&GMC` (조건 없음) | **반영된다.** `initialfunds` 2 → 3 이 로비 초기 자금 "기본" → "많음", 시작 국고 $14.43 B → $57.72 B | 필요 없다 |
| 시나리오 파일 끝에 덧붙인 `&&CVP <지역>` | **반영된다.** `gdpc 99999` → $99,999, `treasury 100000000000` → $100.00 B. 국가 부채는 그대로다 | 필요 없다 |
| 시나리오 파일 끝에 덧붙인 `&&UNITS` 행 | **반영된다.** 비용 66 → $6,373 M. 다만 그 장비가 보유 설계에서 빠지므로 `&&REGIONUNITDESIGNS <지역>` 에 장비 번호를 함께 적어야 목록에 남는다 | 필요 없다 |

- **캐시 재생성 방법**: 로비 → 게임 옵션 → 시스템 탭 → "모드용 캐시 재생성"(Force Recache For Modding) 체크 → 시작. 1분 안에 "캐시 생성 - 완료" 창이 뜨고 **로비로 돌아온다**(게임에 들어가지 않는다). 체크는 저절로 풀리고, 다시 시작하면 새 캐시로 게임이 열린다.
- **재생성하면 게임이 설치 폴더의 `Cache\<이름>.SAV` 를 고쳐 쓴다.** 모드를 지워도 캐시에는 수정된 값이 남는다. 모드를 뺀 뒤에는 한 번 더 재생성하거나 원본 캐시를 되돌려야 한다.
- **시나리오 파일 끝의 `treasury` 는 달러 단위이고 값을 통째로 바꾼다**(`treasury 50000` → 국고 $50.00 K). `*.CVP` 의 "백만 단위, 기본값에 더함" [위키] 과 다르다.
- `&&UNITS` 를 덧붙였을 때 보유 설계를 다시 넣어 주지 않은 다른 지역이 그 장비를 잃는지는 보지 않았다.
- `ignorecache` 는 시험하지 않았다(로비 옵션으로 충분했다). `INI\AllLoad.ini` 가 매번 읽는 파일(AI 매개변수, 지형)도 시험하지 않았다 — 표의 그 줄은 [추정]이다.

시나리오 파일 끝에 덧붙이는 블록의 모양(시험한 그대로):

```
&&CVP 1499
gdpc 99999
treasury 100000000000

&&UNITS
2413, "Leopard 2A7+", 2, …(행 전체, 고칠 값만 바꾼다)

&&REGIONUNITDESIGNS 1499
2413,
```
