# 07. 내장 치트

조사 기준: Steam appid `2093410`, build `21347933`, 2026-10-06. 명령 목록은 실행 파일의 문자열 91개에서, 설명은 공식 위키에서 왔다.

표기: **[확인]** 게임 안에서 직접 확인, **[추정]** 정황으로 판단, **[위키]** 공식 위키에 있으나 이 빌드에서 미확인.

게임에는 `cheat <이름>` 꼴의 명령이 91개 들어 있다 **[확인: 실행 파일 문자열]**. 위키에 설명이 있는 것은 그대로 요약했고,
실행 파일에만 있는 것은 효과를 지어내지 않고 "모름"이라고 적었다. 영역별로 무엇에 쓰는지는 [05 게임 구조](05-game-systems.md)에 있다.

## 넣는 법

1. 게임을 진행하는 중에 `Ctrl+Shift+S` 를 누른다. 설정 화면(Game Settings)이 뜬다. **[위키]**
   `INI\hotkeys.csv` 에 `<Ctrl> + <Shift> + <S>` = "Game Settings" 행이 있다. **[확인: 파일]**
2. 화면 아래의 글자 입력란에 `cheat allowcheats` 를 넣고 Enter. 치트 모드가 켜진다. **[위키]**
   게임 문구에 "So, you need to cheat eh?" 가 있다 — 켜졌을 때 뜨는 문구로 보인다. **[추정: 번역 테이블]**
3. 같은 입력란에 치트를 넣는다.

알아 둘 것: **[위키]**

- 싱글플레이에서만 된다.
- 치트 모드는 그 게임을 끝낼 때까지 꺼지지 않는다.
- 켜고 끄는 치트는 같은 명령을 다시 넣으면 꺼진다.
- `%x` 를 받는 치트(SR2030 에서 새로 생긴 것)는 번호를 주지 않으면 고른 육각의 소유 지역을 쓴다.
- 지역 번호는 `Maps\W2030.CVP` 의 `&&CVP <번호>` 다(독일 1499).

치트를 켜면 Steam 업적이 막히는지는 모른다.

## 출력 명령

치트 입력란에 넣으면 게임이 자료를 파일로 내보내는 명령이다 **[위키]**. 모드를 만들 때 쓸모가 있다(지금 게임 상태에서 전투서열이나
생산량을 뽑는다). 아래 이름은 모두 실행 파일에 문자열이 있다 **[확인: 실행 파일 문자열]**. 어디에 파일을 쓰는지는 확인하지 않았다.

| 명령 | 무엇을 내보내나 |
|---|---|
| `outputoob` | 지금 배치대로의 전투서열 파일. 지역마다 하나. `outputoob sel` 은 고른 부대만, `outputoob <지역 번호>` 는 그 지역만 |
| `outputnav` | 항로점 목록 |
| `outputbz` | 쓰이고 있는 전투 구역 목록 |
| `outputlog` | 로그(로그 설정과 무관하게) |
| `outputsocial` | 전 세계의 사회 지출 값 |
| `outputproduction` | 물자의 생산·소비 값 |
| `outputworldlogmil` | 시설과 부대 수량(세계 균형 조정용) |
| `outputtheatre` | 전구와 전투 구역 배치 두 파일(지도 편집기로 들여올 수 있다) |

실행 파일에는 위키에 없는 `outputqty` `outputthreat` `outputworldlog` `outputworldlogind` `outputoobresvd` 도 있다. 무엇을 내는지는 모른다.
