# ToyBox 사회 — 품질 등급의 배율과 최소 유지

- 날짜: 2026-10-21. 게임 build 21347933.
- 상태: 설계 — 사용자의 승인을 기다린다. 정한 것은 사용자가 2026-10-21 에 골랐다(아래 "정한 것"의 표시).

## 왜

사용자가 사회 항목 여덟(보건 · 교육 · 인프라 · 환경 · 가족 수당 · 치안 · 문화 지원 · 사회 보장)의 **품질 등급**을 다루고 싶어 한다 —
등급이 오르고 내리는 속도를 배율로 바꾸고, 정한 값 아래로 내려가지 않게 한다. 지금 ToyBox 의 "사회 지출" 배율은 국고만 바꾼다(등급은 그대로).

## 게임에서 알아낸 것 (2026-10-21)

**자리** [확인: 정적 + 게임 — 화면 열여섯 값과 맞췄다]: 플레이어 지역 객체의 `+0x15db0 + 4·i`(float, i = 0 보건 … 7 사회 보장)가 품질 등급 G 다.
게임의 사회 지출 화면에서 항목을 누르면 나오는 **"품질 등급 72.3 %" = G × 100**(소수 한 자리), 목록 막대의 풍선말 `NN %` = round(G × 100),
재무 패널의 "평균 사회 점수" = 여덟 G 의 평균 × 100. 상세 화면의 슬라이더는 지출 수준 L(`+0xa680 + 4·i`)을 따른다.

**날마다의 셈** [확인: 정적 — `0x76a040`. 게임의 5일 · 1일 변화와 맞다]: 자정에 항목마다
- r = 기술의 등급 배수(곱 보정 표의 플레이어 칸 100 + i). r > 1.5 면 r = √√r + 0.4.
- L ≤ 0.25 이면 G' = (58·G + r·max(√L / 2, 0.05) + L) / 60, 0.25 < L ≤ 1 이면 G' = (59·G + L·r) / 60, L > 1 이면 G' = (59·G + L^(1/8)·r) / 60.
- G' ≥ 2.0 이면 2.0 으로 자른다.
곧 **등급은 목표(대략 L × r) 쪽으로 남은 거리의 1/60 씩** 움직인다. 독일 보건은 하루 +0.008 쯤.

판을 시작할 때 G 가 0 이면 기본값을 채우는 함수(`0xbbbf40`)가 따로 있다 — 날마다의 셈과는 상관없다.

## 정한 것

| | 정한 것 | 누가 |
|---|---|---|
| 배율의 꼴 | 항목마다 **오를 때 배율**과 **내릴 때 배율**을 따로 | 사용자 |
| 단위 | 항목마다 따로 + 맨 위 **"모든 항목"** 줄로 한꺼번에(물자 탭과 같은 꼴) | 사용자 |
| 최소 유지의 범위 | **0 ~ 999 %**(화면의 품질 등급과 같은 단위) | 사용자 |
| 자리 | 새 탭 **`사회`**(배율 탭 다음) | 사용자 |
| 배율의 범위 | 0 ~ 10000 %(기본 100). 0 % 면 그쪽으로 움직이지 않는다(예: 내림 0 % = 떨어지지 않음) | 제안(내 판단) |
| 스위치 | 탭 맨 위 `등급 배율 적용` 하나 — 꺼져 있으면 배율은 쉰다. 최소 유지는 항목마다의 체크로 켠다(물자 탭과 같다) | 제안 |
| 저장 | 저장되는 설정이다(배율 · 최소 유지처럼). 줄: `social.on`, `social.up.<i>` · `social.down.<i>`(퍼센트), `social.keep.<i>`(0 / 1) · `social.keep.<i>.value`(퍼센트) | 제안 |

## 하는 일

**배율(날마다)**: ToyBox 는 0.5초마다 플레이어의 G 여덟을 읽어 둔다. 날의 칸이 1 … 3 오른 것을 보면(배율의 "날마다의 일"과 같은 판단),
항목마다 그날 게임이 움직인 양 d = G(지금) − G(자정 전에 읽어 둔 값)를 보고
- d > 0 이면 G += (오름 배율 − 1) × d, d < 0 이면 G += (내림 배율 − 1) × d,
- 그 결과를 0 … 2.0 으로 자른다(게임의 끝과 같다). 배율이 100 % 면 쓰지 않는다.
나라가 바뀌거나 날이 뒤로 가면(불러오기) 맞추기만 한다(배율의 날 판단과 같다).

**최소 유지(0.5초마다)**: 켜진 항목의 G 가 정한 값 ÷ 100 보다 작으면 그 값으로 쓴다. 배율보다 뒤에 한다.
200 % 를 넘긴 값은 게임이 자정마다 2.0 으로 자르고, ToyBox 가 다음 틱에 다시 올린다.

**쓰는 곳 · 부르는 함수**: 쓰는 곳은 **플레이어 지역 객체의 품질 등급 8칸(`+0x15db0` … `+0x15dcc`)** 이 는다 — `CLAUDE.md` 와 `game.h` 의 머리말을 함께 고친다.
다른 지역의 등급, 지출 수준, 곱 보정 칸(100 … 115)에는 쓰지 않는다. 부르는 게임 함수는 늘지 않는다.
지금 값이 유한하고 0 이상 10 미만일 때만 쓴다(아니면 그 항목은 건드리지 않는다).

**주소 찾기**: 등급 칸의 자리(`0x15db0`)를 든 서명을 `srkit sig-mine` 으로 뽑는다(날마다의 셈 `0x76a0a0` 의 `lea rdi, [rbx + 0x15db0]` 둘레와 화면 코드의 자리 등, 셋 가운데 둘이 맞으면 된다 — 배율의 규칙과 같다).
못 찾으면 `사회` 탭의 줄이 꺼지고 까닭을 한 줄 보인다.

**창**: `사회` 탭 — 맨 위 `등급 배율 적용` 과 `(?)` 풍선말(등급이 어떻게 움직이는지, 200 % 의 끝). 표의 열: 항목 · 지금 등급(%, 소수 한 자리 — 게임 밖이면 `-`) · 오름 % · 내림 % · 유지(체크) · 유지 값 %.
첫 줄 `모든 항목` 은 고친 값을 여덟 줄에 함께 넣는다. 상태 줄 뒤에 ` · 사회 N개`(배율이 100 이 아닌 것 + 켜진 유지의 수). 1024 × 768 에서 구르지 않고 보이게.

## 하지 않는 것

- 지출 수준(슬라이더)이나 비용은 고치지 않는다. 등급의 목표(곱 보정 칸 100 … 107)에 곱하는 방법은 쓰지 않는다 — 사회 지출 비용 칸이 그 방법으로 듣지 않았다(묶음 7 의 M6).
- 다른 나라의 등급.

## 게임 안에서 볼 것

1. 오름 1000 % — 오르는 항목의 하루 변화가 대조 날의 10배인가(메모리와 상세 화면).
2. 내림 0 % — 지출을 낮춰 내려가는 항목이 그대로인가.
3. 최소 유지 150 % — 다음 틱에 화면이 150.0 % 인가, 자정 뒤에도 남는가. 300 % — 화면 · 평균 사회 점수 · 국내 지지율 등에 무엇이 나타나는가, 게임이 탈 없이 도는가(사흘).
4. 끄기 — 배율과 유지를 끄면 다음 자정부터 게임대로 움직이는가. 다른 나라의 G(둘) · 지출 수준은 그대로인가.
