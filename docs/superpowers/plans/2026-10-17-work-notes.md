## 알아 둘 것

- **시나리오 끝의 `&&CVP` 에 `worldavail` 을 덮어쓰면 게임이 "시작"에서 꺼진다**(원래 값이어도). `gdpc` · `treasury` 는 된다 — [docs/06](../../06-data-reference.md).
- 지역 코드 비트 = 글자 − 'A' + 1 번(독일 `GE` = `0xa0`, `K` = `0x800`, `U` = `0x200000`). 비트 하나가 그 글자를 가진 모든 나라의 설계를 연다(`K` 로 대만 · 미국 일부도).
- 사용자의 `%APPDATA%\SR2030ToyBox\toybox.ini` md5 는 이제 **`55144E4BA4A9F109F8451EEB145430FD`**(2026-10-17 19:11, 사용자가 직접 게임을 했다). 검증 뒤 이것과 견준다.
- `gamedrive.py key` 의 숫자는 16진(`0x32`)으로 준다. `type` 은 ToyBox 입력란에 들어가지 않는다.
- Python 으로 저장소 파일을 고칠 때 `Path.write_text` 는 줄 끝을 CRLF 로 바꾼다 — `write_bytes(s.encode("utf-8"))` 를 쓴다. Git Bash 의 `sed -i` 도 CRLF 파일에서 줄 끝을 망친다.
- `__try` 는 소멸자가 있는 함수 안에 둘 수 없다(C2712) — `hang_owners` · `swap_qword` 처럼 작은 함수로 뺀다.
- 지역 코드를 메모리로 바꿔 보는 버림 스크립트(`regionmask.py`)는 그 세션의 스크래치패드에만 있었다 — 저장소에는 없다.
