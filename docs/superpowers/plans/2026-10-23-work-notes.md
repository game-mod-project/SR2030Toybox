## 아직 보지 않은 것 · 남은 것

- **English 모드에서 시나리오 이름이 깨진다**(`2030 - ì*‚ä³*`) — 한글화를 설치한 채 언어를 English 로 고를 때. 원인 조사 전. 따로 할 일 카드로 제안해 두었다([docs/04](../../04-korean-localization.md)의 "알려진 한계").
- 예비 인원: 생산이 인원 부족으로 **멈추는** 상황은 재현하지 못했다(룩셈부르크는 생산 슬롯이 0). 인구보다 큰 예비를 최소 유지로 여러 날 지킨 판은 보지 않았다. 최소 유지의 끝을 "인구의 몇 %"로 묶을지는 사용자가 정한다(제안만 했다).
- 사회: 200 % 를 넘긴 품질 등급의 효과(지지율 등)는 사흘 안에 보이지 않았고 비용만 올랐다 — 오래는 보지 않았다.
- 유닛 생산 배율: 칸 15 의 경계(×20 은 듣고 ×1000 은 안 들음) 사이는 보지 않았다. 마지막 하루 이틀은 배율과 상관없이 걸린다.
- 앞 메모의 "아직 보지 않은 것"(연 지역이 저장 → 불러오기 뒤에도 남는가 등)은 그대로다.

## 알아 둘 것

- **게임은 자정의 셈 도중에도 메시지를 돌린다** — ToyBox 의 틱이 날의 칸만 오르고 다른 값은 아직 옛 값인 순간에 올 수 있다. 날마다 "게임이 움직인 양"을 보는 기능은
  값이 바뀐 것을 볼 때까지 기다려야 한다(사회의 `SOCIAL_SETTLE_MS`). 연구 속도 배율은 날의 칸만 보면 되어 이 문제가 없었다.
- **검증 도구의 조합키**: `gamedrive.py key` 는 떼기를 수정키 상태표를 되돌린 **뒤에** 보낸다(#111). 앞에 보내면 ImGui 가 Ctrl 을 쥔 것으로 남아 +/− 가 10배 걸음이 됐다.
- **검증 도구로 띄운 게임에서 해상도를 바꾸면 게임이 Steam 을 거쳐 스스로 다시 시작한다** — 그 게임은 **실제 레지스트리 · 실제 ToyBox 설정**으로 뜬다(10-23 에 한 번 그랬고 바로 껐다. 사용자 `toybox.ini` 는 그대로).
  큰 해상도가 필요하면 옵션에서 고른 뒤 재시작 단추를 누르지 말고 `stop` → `start --` 로 띄운다.
- 사용자의 `%APPDATA%\SR2030ToyBox\toybox.ini` md5 는 사용자가 플레이할 때마다 바뀐다(10-23 기준 `131b38d00ac0ae0245b0c5888784805a`). 검증 앞뒤로 그 순간의 값을 견준다.
- 분석용 읽기 도구는 스크래치패드에만 있었다(저장소에 없다): `sr_mem.py`(지역 객체 · 곱 보정 줄 스냅숏), `sr_grades.py`(품질 등급 · 지출 수준), `sr_people.py`(인구 칸 여섯),
  `sr_mulfx.py`(검증 판에서 곱 보정 칸 하나를 곱해 쓰는 분석 전용), 디스어셈블 `sr_w.py` · `sr_d.py`. 없으면 다시 짠다 — 꼴은 [2026-10-10 메모](2026-10-10-work-notes.md)의 "분석 도구".
- GitHub 저장소는 `gmodprj/SR2030Toybox` 다. `gh` 명령에는 `--repo gmodprj/SR2030Toybox`.
