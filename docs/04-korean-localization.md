# 04. 한글화 모드 설계와 준비 상태

## 목표

Supreme Ruler 2030 을 한국어로 표시한다. 새 언어 폴더 `Localize\LOCALKO` 를 추가하는 방식이며 기존 언어와 게임 파일은 그대로 둔다.

성공 기준: (1) 한글이 깨지지 않고 줄바꿈이 맞게 표시된다 (2) 원본 데이터의 악센트 문자(도시·인물 이름)가 그대로 보인다
(3) 번역하지 않은 문구는 영어로 나온다 (4) 설치·제거가 깨끗하다.

## 구성 요소

[03 문서](03-localization-internals.md)의 네 가지 문제에 하나씩 대응한다.

| 구성 요소 | 해결하는 문제 | 위치 |
|---|---|---|
| **디코딩 훅 DLL** (`WTSAPI32.dll` 프록시) | 그리기 CP1252 고정, 폭 측정 | `native/srhook/` → `build/srhook/` |
| **SR-UTF8 인코딩** | 줄바꿈 바이트 0xB6 충돌 | `src/srkit/srutf8.py`, `native/srhook/srdecode.c` |
| **한글 포함 spritefont** | 글리프 없음 | `src/srkit/spritefont.py` |
| **번역 테이블 → LOCALKO** | 텍스트 | `mods/korean/translation/*.csv`, `src/srkit/korean.py` |
| 언어 등록 | 옵션 화면에서 선택 | `INI\UISettings.csv` 수정본 |
| **그림 글자 다시 그리기** | 메뉴·제목·버튼이 그림이라 번역이 안 먹힘 | `mods/korean/sprites.toml`, `src/srkit/sprites.py` |

### 디코딩 훅

게임이 임포트하는 `WTSAPI32.dll` 과 같은 이름의 DLL 을 게임 폴더에 두면 Windows 가 시스템 것보다 먼저 로드한다
(이 DLL 은 KnownDLLs 가 아니다). DLL 은

- 원래 WTSAPI32 의 내보내기 78개를 전부 `C:\Windows\System32\wtsapi32.dll` 로 전달하고,
- 게임 실행 파일의 임포트 테이블에서 `MultiByteToWideChar` 한 칸만 자기 함수로 바꾼다.

바꿔 끼운 함수는 코드페이지가 1252(그리기) 또는 UTF-8(측정)일 때만 SR-UTF8 디코더를 쓰고 나머지는 원래 함수로 넘긴다.
레지스트리 언어가 `LOCALKO` 일 때만 켜지므로 다른 언어로 실행하면 원본과 똑같이 동작한다(`SRHOOK=1`/`0` 환경 변수로 강제 가능).
게임이 옵션 화면에서 언어를 재시작 없이 바꾸므로, 훅은 0.5초마다 언어를 다시 확인한다(시작할 때만 보면 영어로 켠 뒤
한국어를 고른 사용자는 재시작 전까지 깨진 글자를 본다 — 실제로 그랬다).
실행 파일은 디스크에서도 수정하지 않으며, Steam 무결성 검사·게임 갱신에도 DLL 은 남는다.

같은 DLL 에 검증 도구용 기능이 둘 있다. 둘 다 평소 실행에는 영향이 없다.

- **가상 마우스**: 게임은 마우스가 가리키는 곳을 메시지가 아니라 `GetCursorPos` 로 읽는다(툴팁, 버튼 강조, 지도 가장자리
  스크롤). 창을 화면 밖에 두면 툴팁을 볼 수 없으므로, 환경 변수 `SRHOOK_CURSOR=1` 로 띄운 게임에서만 `GetCursorPos` 를 바꿔
  끼워 공유 메모리에 적힌 창 안 좌표를 돌려준다(`gamedrive.py move`/`click`). 실제 마우스는 움직이지 않는다.
- **레지스트리 접근 로그**: `srkit hook-build --trace` 로 만든 진단용 빌드만 `%TEMP%\srhook-trace-<pid>.log` 를 남긴다.

### SR-UTF8

- `¶` 는 단일 바이트 0xB6.
- 그 밖의 비ASCII 문자는 UTF-8, 단 엔진이 바이트 단위로 건드리는 값을 피해 바꿔 쓴다.
  - **연속 바이트 0xB6 은 0xFF** (줄바꿈 기호와 충돌).
  - **3바이트 문자의 선두 바이트 EA·EB·ED·E2 는 E5·E6·E8·E0**, **연속 바이트 9A·9E 는 F7·FE** (지도 라벨 대문자화에 걸림.
    [03 문서](03-localization-internals.md)의 표). 한글의 선두 바이트는 E5·E6·EC·E8 넷이 된다.
  - 바꿔 쓴 값은 모두 그 대문자화 표에 없고, 연속 바이트 대용 FF·F7·FE 는 게임의 텍스트 데이터 1,790개 파일에 한 번도 나오지 않는다.
  - 대가: 선두 바이트 자리를 내준 문자(U+0800–0FFF, U+5000–6FFF, U+8000–8FFF — 한자 일부)는 쓸 수 없다. `srkit check` 가 잡는다.
- 디코더는 유효한 시퀀스가 아닌 바이트를 CP1252 문자로 취급한다 → `São Paulo` 같은 원본 데이터가 그대로 읽힌다.
  바꿔 쓰기 전의 바이트도 그대로 읽는다(이전 빌드가 남긴 문자열 대비).
- **텍스트 파일과 훅 DLL 은 짝이 맞아야 한다.** 인코딩을 바꾸면 둘을 함께 설치해야 하고, 게임이 실행 중이면 DLL 이 잠겨 있으므로
  `srkit deploy --apply` 는 실행 중에 설치를 거부한다.
- 측정 경로에 한 바이트만 들어오면: 3바이트 리드(0xE0–0xEF) → U+E000(한글 한 칸 폭), 연속 바이트 → U+E001(폭 0).
  글꼴에 이 두 자리표시 글리프를 넣어 둔다.

### 지도 이름 (도시·시설 위치)

지도 위 이름은 지도 데이터(`Maps\*.OOF`)에 있어 현지화 파일로는 바꿀 수 없다. 사용자 결정(2026-10-06)으로 전부 한글로 적는다.

- `srkit extract` 가 `*.OOF` 의 이름 칸에서 서로 다른 이름을 뽑아 `translation/map-names.csv` 로 만든다(키 `MAPNAME|<이름>`).
- `srkit build` 가 `Localize\LOCALKO\srhook-names.txt` 를 만든다: 한 줄에 `게임이 그리는 바이트<TAB>SR-UTF8 한글<LF>`.
  "게임이 그리는 바이트"는 원래 이름에 게임의 대문자화를 적용한 것이다.
- 훅은 그리기·측정 호출의 문자열이 사전의 이름과 **통째로 같을 때** 한글 이름으로 바꿔 디코딩한다. 한국어일 때만 동작하고
  게임 파일은 그대로다.
- 제약
  - 한글 이름의 글자 수 ≤ 원래 이름의 글자 수. 게임이 그리기 버퍼를 원래 문자열의 바이트 수만큼만 잡아서, 넘으면 뒤가 잘린다.
    음역은 거의 항상 더 짧다. `srkit check` 가 검사한다.
  - 통째로 같아야 하므로 이름이 다른 글자와 이어 붙어 그려지는 곳(문장 속 도시 이름 등)은 바뀌지 않는다.
  - 도시 이름과 철자가 같은 다른 문구도 바뀐다. 번역하지 않고 영어로 그려지는 문구(GUI 의 `NATO` 등)와 같은 이름은
    빌드가 사전에서 뺀다. 유닛·함선 이름이 도시 이름과 같으면 한글로 바뀔 수 있다(확인하지 않았다).
- 표기 지침은 [MT-MAPNAMES.md](../mods/korean/MT-MAPNAMES.md). 이름만 보고 적은 음역이라 작은 마을일수록 틀릴 수 있다.

### 글꼴

원본 spritefont 의 라틴 글리프 픽셀은 그대로 두고(화면이 원본과 동일), 한글 등을 더해 텍스처를 다시 채운다.
추가 문자: KS X 1001 한글 2,350자 + 호환 자모 + 기호 몇 개 + **번역문에 실제로 쓰인 그 밖의 문자**(빌드 때 자동 수집).
한글 크기는 원본 글꼴의 대문자 높이에 맞추고, 기준선과 왼쪽 여백도 원본 글리프에서 추정해 맞춘다.
39개 글꼴 합계 약 74MB, 빌드 약 14초.

### 그림 글자

`Localize\<언어>\Graphics\Skin0|Skin5\SRBITS5.png` (2048x2048) 안에 그림으로 들어 있는 문구 106개(스킨당)를 한글로 다시 그린다.
어느 영역이 어떤 그림인지는 게임의 `INI\Bitmaps.csv` 5번 페이지 항목에서 읽고(상태별 사각형 × 프레임), 문구는
`sprites.toml` 에 프레임 순서대로 적는다. 그림 종류에 따라 처리한다.

| 종류 | 대상 | 처리 |
|---|---|---|
| `float` | 옵션·로비 탭(4가지 상태), 화면 제목, 일시 정지 | 투명 바탕이므로 비우고 새로 그린다. 선택 상태의 밑줄, 마우스 올림 상태의 광채도 다시 만든다 |
| `plate` | 버튼, 메인 메뉴 카드의 이름판 | 글자를 찾아 옆의 빈 판을 이어 붙여 지우고 그 위에 쓴다 |
| `photo` | 현대 스킨의 튜토리얼 카드(사진 위에 글자) | 글자 덩어리만 골라 둘레 색으로 메우고 쓴다 |

버튼 판은 반투명이고 영어 글자 모양이 알파 채널에도 남아 있어, 색과 알파를 함께 지워야 흔적이 남지 않는다.

## 작업 흐름

```
uv run srkit extract      # 영문 원문 → mods/korean/translation/*.csv (기존 번역 유지, 원문 변경 보고)
(번역: ko 열 채우기)
uv run srkit check        # 토큰·금지 문자 검증
uv run srkit stats        # 진행률
uv run srkit hook-build   # 훅 DLL (MSVC Build Tools 필요)
uv run srkit build        # build/korean/ 생성
uv run srkit deploy korean          # 설치 미리보기
uv run srkit deploy korean --apply  # 게임 폴더에 설치
```

**설치만으로는 한국어가 되지 않는다. 언어를 한 번 골라야 한다.** 게임을 켜서 옵션(톱니) → `FILES` → `Game Language` →
`Korean` 을 고르면 재시작 없이 바로 바뀐다(되돌릴 때는 같은 자리에서 `English`). 훅 DLL 도 이 값을 보고 켜진다.
레지스트리 값을 직접 넣어도 같다:

```
reg add "HKCU\Software\BattleGoat\Supreme Ruler 2030" /v "Language File" /d LOCALKO /f
```

이 명령은 **일반 터미널(시작 → cmd)** 에서 실행해야 한다. Claude 데스크톱 앱(MSIX 패키지) 안에서 도는 셸의 `reg add` 는
앱 전용 가상 레지스트리에 쓰여, 그 셸이 띄운 게임에만 보이고 Steam 이 띄운 게임에는 보이지 않는다(2026-10-06 에 겪음.
이 저장소의 검증용 게임 실행은 전부 그 가상 값으로 돈 것이다).

번역 테이블 형식: `key,en,ko,status` (UTF-8 BOM, Excel 에서 열림). 키는 `섹션|행키|문자열순번`.
`status` 는 `mt`(기계 번역 초안) / `ok`(사람이 확인함).

번역은 **기계 번역 초안 → 사람 검수** 로 진행한다(2026-10-06 결정).
초안은 `mt-export` 로 청크를 뽑아 번역하고 `mt-check` / `mt-import` 로 검증·병합한다
([mods/korean/README.md](../mods/korean/README.md)). 규칙은 [STYLE.md](../mods/korean/STYLE.md), 용어는
[glossary.csv](../mods/korean/glossary.csv). 검사는 서식 토큰의 **순서**까지 본다 — `%s` 는 위치로 값이 들어가므로
한국어 어순 때문에 순서가 바뀌면 뜻이 뒤바뀐다.

## 검증 현황

**확인됨** (자동 테스트 46개, `uv run pytest`)

- 6개 언어의 모든 현지화 텍스트가 파서를 거쳐 바이트 단위로 왕복된다.
- 원본 spritefont 39개를 읽어 다시 쓰면 원본과 일치한다.
- SR-UTF8 이 한글 11,172자 전부에서 0xB6 을 내지 않고 왕복된다.
- 빌드된 훅 DLL 의 디코더가 파이썬 구현과 같은 결과를 낸다(무작위 3,000건, 그리기·측정 두 경로).
  게임의 버퍼 사용 방식(널 자리 없는 호출)과 WTSAPI32 함수 전달도 확인.
- 번역 20건을 넣은 빌드 산출물이 올바르게 디코딩된다. 글꼴 미리보기로 한글·라틴 혼용 간격과 기준선을 눈으로 확인.
- 설치·제거가 가짜 게임 폴더에서 원상 복구된다.

**게임 안에서 확인됨** (2026-10-06, 게임 12.1.1360, 창 모드 1024x768, `scripts/gamedrive.py` 로 실행·캡처)

- 프록시 `WTSAPI32.dll` 이 게임 폴더에서 로드되고 시스템 `wtsapi32.dll` 도 함께 로드된다. 충돌 없이 지도 화면까지 진입.
- 한글이 깨지지 않고 표시된다: 첫 실행 안내 화면, 샌드박스 로비, 지도 화면의 국가 이름.
  `부대` `풍부한` `분야` 처럼 표준 UTF-8 이면 0xB6 이 걸리는 글자도 정상.
- `¶` 줄바꿈(안내 화면의 선택지), **자동 줄바꿈과 가운데 정렬**(로비의 국가 소개 3줄), 줄 맨 앞 `\42 ` 코드가 정상 동작.
- 옵션 → FILES → Game Language 목록에서 `Korean` 을 고를 수 있다. 영어로 켠 게임에서 고르면 재시작 없이 메뉴와 옵션 화면이
  한글로 바뀐다(1600x900 창). 처음에는 목록 끝(7번째)에 넣었는데 **목록이 앞의 6개만 보여 줘서 고를 수 없었고**, 현재 값
  표시에 `Korean` 이 보인 것을 "목록에 나온다"고 잘못 적었었다. 2번째에 넣도록 고친 뒤 다시 확인했다.
- 번역하지 않은 문구는 영어로 나온다. 글꼴 텍스처 확대(최대 4096px)에 따른 문제는 보이지 않았다.
- 번역 검사(`-tcheck`)로 찾은 문구가 번역 후 화면에 나온다: 옵션의 `게임 속도 가속`, 게임 옵션의 `감염 수준` `제재 시스템`
  `모드용 캐시 재생성`(앞의 셋은 공식 번역에도 없던 문구, 마지막은 대소문자만 다른 키만 있던 문구).
  다시 검사한 로그에 "번역이 있는데 찾지 못한 문구"는 0건 — 끝에 공백이 붙은 키(`Show for `)도 맞게 찾는다.

- **지도 화면 훑어보기**(샌드박스 독일, 캡처 52장은 `build/preview/survey/`): 부서 패널 7개(국토·외교·재무·자원·연구·국방·지휘),
  나라 정보 창의 탭 7개(지역 정보·재무·자원·연구·국방·장관 우선순위), 감염 보고, 유닛 주둔·시설·보급망·전구 제어 창,
  게임 중 메뉴, 단축키 목록. 깨진 글자는 없었고 UI 문구는 한글로 나온다. 지도의 도시 이름(`BERLIN` `MÜNCHEN`)은
  악센트까지 원문 그대로 보인다. 번역 검사로 추가한 감염 보고 문구 15개와 `표시 대상`(`Show for `)이 화면에 나온다.
  여기서 본 오역은 고쳤다(아래 "초안의 한계").

- **두 번째 훑어보기**(1600x900 창, 가상 마우스로 툴팁까지. 캡처 `build/preview/survey/110~349`, 잘라 모은 것은 `montage/`):

**초안의 한계 — 검수에서 볼 것**

- `uv run srkit consistency`: 같은 영어 원문이 서로 다르게 번역된 곳 271건. 문맥이 달라 정당한 것과 통일할 것이 섞여 있다

  `Treaty Integrity`(이행도/신뢰도 혼용 → 신뢰도), `Sustainability`(지속 가능성 → 지속 기간), 자원의 `RESERVES`(예비 전력 → 비축분),

  게임 폴더 `HAPS\*.HAPX`(화면 정의, 텍스트 파일)에서 `"문구"` 를 찾으면 알 수 있다.

## 게임 안 검증에서 새로 알게 된 것

- **글자 수가 고정된 자리가 있다.** 날짜의 월 약칭(`Jan`…)은 게임이 앞 3바이트만 잘라 쓴다. `7월` 을 넣으면 `7i*` 로 깨진다.
  이런 키는 [notranslate.txt](../mods/korean/notranslate.txt)에 적어 두면 빌드가 번역을 무시한다. 긴 월 이름(`July` → `7월`)은 문제없다.
  비슷한 자리가 더 있을 수 있으니 검수 때 깨진 글자가 보이면 여기에 추가한다.
- **게임은 긴 제목을 바이트 단위로 자른다.** 한글 음절 중간에서 잘리면 끝에 리드 바이트만 남아 `ì` 같은 글자로 보였다.
  디코더가 "한글이 섞인 문자열의 맨 끝에 남은 리드 바이트"를 버리도록 고쳤다(한글이 없는 문자열이면 `Bogotá` 같은
  원본 이름의 끝 글자이므로 그대로 둔다).
- **지역 이름은 30바이트(한글 10자)까지만 보인다.** 시험용 이름으로 재 보니 10자까지 나오고 11자째부터 잘렸다.
  `srkit check` 가 이 제한을 검사한다(`korean.BYTE_LIMITS`). 종주국 접두어와 붙여 보여 주는 목록(게임 중 메뉴의 "관련 지역")은
  합쳐서 24바이트라 `Egyptian 수에즈 운하 지대` 가 `Egyptian 수에즈 운` 으로 잘린다.
- **지역 이름의 출처는 둘이다.** 현지화 파일(`LocalText-Regions.csv`)에 행이 있으면 그것을, 없으면 지역 데이터(`.CVP`)의 영어
  `regionname` 을 쓴다. 공식 번역에서도 빠져 있는 7곳(유엔, 수에즈 운하 지대, 쿠르디스탄, 포클랜드 제도, 관타나모 등)은
  한국어판에만 행을 추가했다(`localtext-regions.extra.csv`).
- **접두어(`American`, `Egyptian` …)는 번역할 길이 없다.** 지역 데이터의 `prefixname` 이고 현지화 파일에 대응 항목이 없다
  (독일어판 등에서도 영어 그대로). `American 북마리아나` 처럼 섞여 보인다.
- **도시 이름은 현지화 파일이 아니라 지도 데이터에 있다.** `Maps\World2030.OOF`(지도 위 물체 목록, 텍스트)의 각 행에
  `번호, x, y, "HANNOVER", …` 꼴로 대문자 이름이 들어 있고(이름 있는 행 21,980개, 서로 다른 이름 9,958개.
  `Arena 6A` 지도까지 합치면 9,999개), 공식 번역판에서도 원어 그대로 나온다(`MÜNCHEN` `KÖLN`). 지도를 확대하면 보이는
  도시 라벨과 국토 패널의 위치 이름이 이것이다. 번역하려면 (가) 지도 파일을 고치거나 — 모든 언어에 적용되고 한국어가
  아닐 때는 깨진 글자가 된다 — (나) 훅이 그리는 순간에 이름을 바꿔 줘야 한다. (나)로 했다(아래 "지도 이름").
- **시나리오 전용 현지화 파일은 2개뿐이다**: `Scenario\Arena 6A\Localize\LOCALEN\Arena_localTTRX.csv`,
  `Scenario\Battle of Russia 2030\Localize\LOCALEN\Battle of Russia-Text.csv`. 같은 자리의 `LOCALKO` 폴더로 번역본을 낸다.
  캠페인 정의가 가리키는 `C_Ger-Text.csv` 등은 게임에 들어 있지 않고, 이벤트 파일에는 문구가 없다(뉴스 항목 번호만 참조).
  Battle of Russia 의 지역 이름(`Moscow` 등)은 그 시나리오 파일이 이름 칸을 비워 둬서 영어로 남는다.
- **지역 검색란에 한글을 넣을 수 없다.** 입력란이 바이트를 변형해 받는다(한글 입력 미지원과 같은 원인).
- **같은 영어가 뜻이 다른 자리에 쓰인다.** `LAND` 는 부서 이름(국토)인데 병과(지상)로도 쓰이고, `Systems` 는 옵션 탭(시스템)인데
  자매작의 성계로 옮겨졌었다. 문맥 없이 번역되는 GUI 문구는 화면에서 봐야 잡힌다.

- **공식 번역의 GUI 키 목록은 불완전하다.** 다른 5개 언어 파일의 합집합에도 없는 문구가 화면에 나온다(제재·감염 관련 화면,
  정부 상세, 해협·운하 통행 옵션, `Boosted Game Speed` 등 — 공식 번역판에서도 영어로 나오는 것들). `-tcheck` 로그로 190개를 찾아
  키 목록에 더했다(`srkit tcheck-import`, 절차는 [mods/korean/README.md](../mods/korean/README.md)).
- **GUI 사전은 대소문자까지 똑같은 키로만 찾는다.** 사전에 `Force Recache For Modding` 만 있을 때 화면의
  `Force Recache for Modding` 은 영어로 나왔고, 똑같은 키를 넣자 번역됐다. 그래서 `LAND`(부서) 와 `Land`(병과) 처럼
  대소문자만 다른 키에 서로 다른 번역을 줄 수 있다. 로그의 `Incorrect Case` 는 똑같은 키가 있어도 적히므로
  그 줄 수(197종)는 줄지 않는다 — 봐야 할 것은 `Missing` 이다([docs/03](03-localization-internals.md)).
- **`-tcheck` 로그는 저장 폴더에 쓰인다**: `문서\My Games\Supreme Ruler 2030\Savegame\LOG-TRANS-CHECK.log`.
  폴더가 없으면 조용히 건너뛴다. 게임은 시작할 때 로그를 쓰고 평소처럼 메인 메뉴로 간다.
- **이 PC 는 Windows "제어된 폴더 액세스"가 켜져 있다.** 처음에는 게임이 문서 폴더에 쓰지 못해 저장·로그가 안 됐다
  (Defender 이벤트 1123 에 `SupremeRuler2030.exe` 차단 기록). 사용자가 Windows 보안에서 게임을 허용한 뒤(2026-10-06)
  저장 폴더가 만들어지고 로그가 쓰인다. 다른 PC 에서도 같은 증상이면 이 설정을 볼 것.
- **제목·탭·버튼 상당수는 글자가 아니라 그림이다.** `Localize\<언어>\Graphics\Skin0|Skin5\SRBITS5.png` (2048x2048)에
  들어 있다: 메인 메뉴 카드(TUTORIAL, CAMPAIGN, SANDBOX, LOAD, ONLINE), 화면 제목(OPTIONS, SINGLE PLAYER, MULTIPLAYER,
  CAMPAIGN, LOAD, CREDITS), 옵션 탭(GENERAL … HOTKEYS, 상태별 4벌), 버튼(START, BACK, LOAD, HOST, RESET, JOIN, READY),
  QUIT GAME / SAVE & QUIT / QUIT TO DESKTOP, GAME PAUSED, 튜토리얼 카드. 이 그림을 한글로 다시 그려야 해당 문구가 바뀐다.
- 난이도 값(`Normal`), `Low`, 날짜(`Jul 25, 2023`) 등은 GUI 사전이 아니라 `Variables.ini` 쪽 문구다.
- **옵션에서 언어를 바꾸면 대부분은 바로 바뀌지만 전부는 아니다.** 시작할 때 읽어 둔 목록(로비의 샌드박스 이름
  `2023 - World` 등)은 다시 켤 때까지 이전 언어로 남는다. 한국어를 고른 뒤 게임을 한 번 다시 켜는 것이 좋다.
- **자리가 좁아 이름이 잘리는 곳이 더 있다.** 기술 경쟁 창의 카드 제목은 27바이트(한글 9자) 근처에서 잘린다
  (`고급 컴퓨터 입력 장`, `암흑 에너지 반응 엔` → 줄여서 고침). 왼쪽 위 뉴스 팝업의 제목 칸은 폭으로 잘린다
  (한글 18자 폭쯤. `Supreme Ruler 2023에 오신 것을 환` → 줄여서 고침. 뉴스 제목 2,825개 중 40바이트를 넘는 69개가 후보이고,
  영어 원문도 긴 제목은 그 칸에서 잘린다). 지역 지도책에서는 접두어가 붙은 긴 지역 이름이 옆 숫자 칸과 맞닿는다.
- **게임은 마우스 위치를 `GetCursorPos` 로 읽는다.** 창을 화면 밖에 두면 툴팁·버튼 강조가 동작하지 않아, 검증할 때는 훅의
  가상 마우스(`gamedrive.py move`)를 쓴다. 마우스를 창 가장자리에 두면 지도가 계속 스크롤된다.
- 게임을 처음 실행하면 조작 방식·저장 위치·난이도·UI 배율을 고르는 안내 화면이 뜬다. `-window` 로 실행하면 창 모드가 설정에 저장된다.
- **게임 창이 화면에 보이지 않아도 검증할 수 있다.** 창을 모니터 바깥 좌표에 두어도 `PrintWindow` 캡처와 메시지 입력이 된다
  (`gamedrive.py start` 가 그렇게 띄운다). 게임은 시작하면서 창을 다시 만들어(1920x1080 → 1044x811) 화면 가운데로 옮기므로,
  드라이버가 잠잠해질 때까지 창을 밖으로 보내고, 게임이 포커스를 쥐면 쓰던 창에 돌려준다. 네 번 띄워 조치 횟수는 10, 308, 2, 2회였다.
  횟수를 나눠 센 실행에서는 창 옮김 2회·포커스 반환 0회였고, 308회였던 실행은 무엇을 되돌렸는지 기록이 없어 원인을 모른다
  (사용자가 창을 꺼내 보려던 것과 다퉜을 수도 있다). 그래서 지켜보는 시간을 창이 뜬 뒤 20초로 제한했다.
  최소화하면 그려지지 않아 캡처가 안 된다.

## 알려진 한계

- **한글 입력**: 입력란의 커서 위치가 바이트 수로 계산되어 한글 뒤에서 어긋난다. Steam 닉네임의 한글은 `?` 로 바뀐다(게임이 CP1252 로 저장).
- 3바이트 문자(`…` `—` 곡선 따옴표 등)는 줄바꿈 계산에서 한 칸 폭으로 잡힌다 → 빌드 때 ASCII 로 바꿔 쓴다.
- 문자열 안에 큰따옴표를 쓸 수 없다(파일 형식 제약). 인용은 작은따옴표로.
- 그림 글자는 원본과 글꼴·질감이 같지 않다(Noto Sans/Serif KR 로 다시 그림). `일시 정지` 는 원본의 스텐실 질감 대신 단색이고,
  현대 스킨 튜토리얼 카드는 영어를 메운 자리가 약간 뭉개져 보인다. 기본 스킨(Skin0)과 튜토리얼 카드는 게임 화면에서 보지 못했다.
- 훅 DLL 의 전달 경로가 `C:\Windows\System32` 로 고정이다(빌드한 PC 의 시스템 폴더).
- DLL 은 Workshop 으로 배포할 수 없어 사용자가 한 번 직접 넣어야 한다.

## 결정이 필요한 사항

- **글꼴 라이선스**: 지금은 Windows 에 설치된 `NotoSansKR-VF.ttf`(SIL OFL)를 쓴다. 배포물에 글리프 이미지가 들어가므로
  OFL 계열(Noto Sans KR, Pretendard, 나눔고딕)이면 문제없고, 맑은 고딕 등 재배포 불가 글꼴은 피해야 한다.
- **번역 방식**: 24만 단어다. 기계 번역 초안 + 검수로 갈지, 범위를 줄여(GUI·핵심 문구 우선) 수작업할지.
- **배포**: Workshop(텍스트·글꼴) + DLL 별도 안내, 또는 전체를 하나의 압축 파일로.
- **원문 포함 여부**: 번역 테이블에 게임 원문(영어)이 들어 있다. 저장소를 공개할 경우 저작권을 고려해야 한다.
