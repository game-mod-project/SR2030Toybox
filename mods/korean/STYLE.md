# 번역 규칙

기계 번역 초안과 사람 검수 모두 이 규칙을 따른다. 용어는 [glossary.csv](glossary.csv)가 우선이다.

## 반드시 지킬 것 (어기면 게임에서 깨진다)

1. **서식 토큰을 그대로, 같은 순서로 둔다.** `%s` `%d` `%.1f` `%%` 는 게임이 순서대로 값을 끼워 넣는다.
   한국어 어순 때문에 순서가 바뀌려 하면 **문장을 바꿔 써서 원문과 같은 순서로** 나오게 한다.
   - 원문 `Military Aid for %s against %s Approved!`
   - 틀림 `%s에 맞선 %s 군사 지원 승인!` (두 나라가 뒤바뀜)
   - 맞음 `%s 군사 지원(대상: %s) 승인!`
2. **`¶` 는 줄바꿈이다.** 개수와 위치(문단 구조)를 유지한다.
3. **줄 맨 앞의 `\42 ` `\LEF` `\CEN` `\RIG` 같은 코드는 한 글자도 바꾸지 않는다.** `\42 ` 는 뒤의 공백까지가 코드다.
4. **큰따옴표 `"` 를 쓰지 않는다.** 인용은 작은따옴표 `'`.
5. 줄바꿈 문자·탭을 넣지 않는다.

## `%s` 뒤의 조사

끼워 넣는 말의 받침을 알 수 없다. 다음 순서로 해결한다.

1. 조사가 필요 없게 쓴다: `%s: 자원 부족`, `%s 정부`, `%s 측`, `%s 지역`.
2. 그래도 필요하면 병기한다: `%s이(가)`, `%s은(는)`, `%s을(를)`, `%s와(과)`, `%s(으)로`.

## 문체

- **버튼·라벨·목록 항목**: 명사형으로 짧게. `Build Unit` → `유닛 생산`, `Show Obsolete Units` → `구형 유닛 표시`.
- **보고·이메일·설명문·시나리오 소개문**: 합니다체. `We are currently experiencing…` → `현재 … 겪고 있습니다.`
  화자가 누구든(어느 나라의 브리핑이든) `~다` 로 끝나는 평서체를 쓰지 않는다.
- **뉴스 제목**: 명사형 종결. `City Liberated` → `도시 해방`.
- **장관의 권고·질문**: 합니다체 높임. `Shall we offer assistance?` → `지원을 제안할까요?`
- 전부 대문자인 원문도 한국어는 평범하게 쓴다(`ACTIVATE` → `활성화`). 같은 말의 대소문자 변형은 같은 번역.
- 화면 칸이 좁다. **라벨은 원문보다 길어지지 않게**(한글 한 글자 ≈ 영문 두 글자 폭).
- 문장부호는 ASCII(`...`, `-`, `'`). 가운뎃점 `·` 은 써도 된다.

## 번역하지 않는 것 (ko 를 빈 문자열로 둔다)

- 형식·코드·식별자: `mm/dd/yy`, `udef0`, `16 Bit`, `%s`, 파일 이름, URL, 기호만 있는 문자열.
- 영어 약어로 통용되는 것은 그대로 둔다: `GDP`, `AI`, `UI`, `HUD`, `MLRS`, `VTOL`, `NBC`, `UN`, `EU`, `NATO`.
- 무기·장비의 고유 모델명. (종류 이름은 번역: `Destroyer` → `구축함`)
- 뜻을 알 수 없거나 내부용으로 보이는 문자열. 억지로 옮기지 않는다.
- 2~4글자 대문자 약어 코드(전구 약어 `NEA`, 계급·분류 약칭 등).
- 영어 서수 접미사(`st` `nd` `rd` `th`)처럼 한국어에 대응이 없는 조각.

원문의 오타(`Departement`, `missilles`)는 의도한 뜻으로 옮긴다.

## 고유명사

- 국가·도시 이름은 국립국어원 외래어 표기와 통용 표기를 따른다(`Germany` → `독일`, `Côte d'Ivoire` → `코트디부아르`).
- 가상의 분열 국가 이름은 뜻이 통하게 옮긴다(`West Ukraine` → `서우크라이나`, `Central Siberia` → `중앙시베리아`).
- 인물 이름은 통용 표기.

## 검수 표시

번역 테이블의 `status` 열: `mt` = 기계 번역 초안, `ok` = 사람이 확인함. 검수하면서 고친 행과 그대로 통과시킨 행 모두 `ok` 로 바꾼다.
