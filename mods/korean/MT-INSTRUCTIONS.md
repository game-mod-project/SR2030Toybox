# 기계 번역 작업 지침 (청크 번역자용)

Supreme Ruler 2030(현대전 배경 지정학 전략 게임)의 영어 문구를 한국어로 옮긴다.
작업 대상 청크와 범위는 작업 지시에 적혀 있다. 이 문서는 **방법**만 다룬다.

## 입력과 출력

- 입력 `<이름>.in.jsonl` : 한 줄에 `{"key": "...", "en": "..."}`
- 출력 `<이름>.out.jsonl` : 한 줄에 `{"key": "...", "ko": "..."}` — 입력과 **같은 key, 같은 순서, 같은 줄 수**, UTF-8.
- 출력 파일은 입력과 같은 폴더에, 청크 하나당 Write 도구 한 번으로 쓴다.

## 먼저 읽을 것

- `E:\SR2030ToyBox\mods\korean\STYLE.md` — 번역 규칙. 어기면 게임에서 글자가 깨진다.
- `E:\SR2030ToyBox\mods\korean\glossary.csv` — 용어집. 해당 용어는 여기 적힌 번역을 쓴다.
- `E:\SR2030ToyBox\build\mt-ref\region-names.tsv` — 이미 확정된 국가·지역 이름(영어 → 한국어). 문장 안에 나라 이름이 나오면 이 표기를 쓴다.

## 방법

- **번역은 직접 한다.** 번역 API, 번역 스크립트, 사전 치환 코드로 만들어 내지 않는다.
- 모든 행을 빠짐없이 처리한다. 번역하지 않기로 한 행(STYLE.md "번역하지 않는 것")도 `{"key": ..., "ko": ""}` 로 줄을 남긴다.
- JSON 이스케이프: 원문에 `\42 ` 같은 코드가 있으면 JSON 에서는 `"\\42 ..."` 로 쓴다(백슬래시 두 개, 뒤 공백 유지). `¶` 는 그대로 쓴다.
- `%s` `%d` 등 서식 토큰은 **원문과 같은 순서**로 둔다. 어순 때문에 순서가 바뀌려 하면 문장을 바꿔 쓴다.
- key 는 글자 그대로 복사한다.

## key 로 보는 문맥

| key | 내용 | 쓰는 법 |
|---|---|---|
| `TTRTEXT|<id>|0` | 기술 이름 | 짧은 명사형. 같은 계열(`… I`, `… II`, `Advanced …`, `Improved …`)은 같은 틀로 |
| `TTRTEXT|<id>|1` | 기술 설명 | 합니다체. 문장이 아닌 메모(`----- Parking Meters, …`)는 앞 기호를 두고 명사 나열로 |
| `REGIONTEXT|<id>|1` | 국가·지역 소개문 | 합니다체. `\42 ` 로 시작하면 그대로 시작. 나라 이름은 region-names.tsv 표기 |
| `NEWSITEMSTEXT|<id>|0` | 뉴스·이메일 항목의 짧은 제목 | 명사형. `// ` 로 시작하면 그 접두는 그대로 둔다 |
| `NEWSITEMSTEXT|<id>|1` | 머리기사(제목 줄) | 명사형 종결. `%s` 순서 유지 |
| `NEWSITEMSTEXT|<id>|2` 이후의 긴 글 | 본문. 장관·참모가 지도자(플레이어)에게 올리는 보고이거나 뉴스 기사 | 합니다체. `We` 는 `우리`, `our region` 은 `우리 지역` |
| `NEWSITEMSTEXT|<id>|n` 의 짧은 글(`Acknowledge`, `Agree`, `Offer Assistance` …) | 응답 버튼 | 아주 짧은 명사형·동사 원형(`확인`, `동의`, `지원 제안`) |

같은 id 의 행들은 한 항목이다. 제목·본문·버튼이 서로 맞게 옮긴다.

## 검증

청크마다 다 쓴 뒤 아래 명령(PowerShell)을 실행해 **"문제 0건"** 이 될 때까지 출력 파일을 고친다.

```
uv run --directory E:\SR2030ToyBox srkit mt-check E:\SR2030ToyBox\build\mt\<청크이름>.in.jsonl
```

## 보고 형식

청크별로 한 줄: 파일 이름, mt-check 결과 줄(통과 수/전체, 미번역 표시 수, 문제 수).
그 아래에: (1) 끝내 고치지 못한 문제가 있으면 그 행과 이유 (2) 용어집에 없어서 번역어를 스스로 정한 주요 용어 최대 10개 (`영어 → 한국어`) (3) 규칙이 모호했던 점(있을 때만, 짧게).
