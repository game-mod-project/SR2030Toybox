# 지도 이름 한글 표기 지침 (map-names.csv 청크 작업용)

게임 지도에 나오는 도시·시설 위치 이름을 한글로 적는다. 번역이 아니라 **한글 표기(음역)** 작업이다.

## 입력과 출력

- 입력 `<청크>.in.jsonl`: 한 줄에 `{"key": "MAPNAME|HANNOVER", "en": "HANNOVER"}`
- 출력 `<청크>.out.jsonl`: 같은 순서로 한 줄에 `{"key": "MAPNAME|HANNOVER", "ko": "하노버"}`
  - `key` 는 입력과 글자 하나 다르지 않게 그대로 쓴다. 입력의 모든 줄에 대해 한 줄씩 쓴다(빠뜨리거나 더하지 않는다).
  - 파일은 UTF-8, JSON 문자열 규칙대로(작은따옴표 `'` 는 그대로, 역슬래시는 쓰지 않는다).

## 이름의 성격

- 전부 대문자다. 대부분 **현지어 철자나 로마자 표기**이고 영어 이름이 아닐 때가 많다:
  `MÜNCHEN`(뮌헨), `WIEN`(빈), `ROMA`(로마), `FIRENZE`(피렌체), `WARSZAWA`(바르샤바), `MOSKVA`(모스크바), `LISBOA`(리스본),
  `ATHINAI`(아테네), `TARABULUS`(트리폴리), `AL QAHIRAH`(카이로), `KRUNG THEP`(방콕), `XI'AN`(시안).
- 악센트가 빠진 것도 있다: `KOBENHAVN`(코펜하겐).
- 도시가 아닌 것도 섞여 있다(광산·호수·기지 등): `CIGAR LAKE`(시가호), `FORT MCMURRAY`(포트맥머리).

## 표기 규칙

1. **어느 곳인지 먼저 알아본다.** 한국에서 널리 쓰는 이름이 있으면 그것을 쓴다(국립국어원 외래어 표기법과 관용 표기).
   `PARIS` 파리, `LONDON` 런던, `NEW YORK` 뉴욕, `LOS ANGELES` 로스앤젤레스, `BEIJING` 베이징, `TOKYO` 도쿄,
   `SÃO PAULO` 상파울루, `BUENOS AIRES` 부에노스아이레스, `KÖLN` 쾰른, `VENEZIA` 베네치아, `PRAHA` 프라하.
2. 알아볼 수 없는 이름은 **철자가 속한 언어의 발음**으로 외래어 표기법에 따라 적는다(영어식으로 읽지 않는다).
   독일어 `STUTTGART` 슈투트가르트, 스페인어 `GUADALAJARA` 과달라하라, 프랑스어 `MARSEILLE` 마르세유,
   폴란드어 `ŁÓDŹ`/`LODZ` 우치, 러시아어 `NIZHNIY NOVGOROD` 니즈니노브고로드, 아랍어 `AL BASRAH` 바스라.
3. 중국 이름(병음)은 중국어 표기법으로: `CHENGDU` 청두, `HARBIN` 하얼빈, `GUANGZHOU` 광저우.
   일본 이름은 일본어 표기법으로: `SENDAI` 센다이, `OSAKA` 오사카. 한국·북한 이름은 한국어 이름으로: `PUSAN` 부산, `TAEGU` 대구.
4. **띄어 쓰지 않는다.** `NEW YORK` 뉴욕, `RIO DE JANEIRO` 리우데자네이루, `CIGAR LAKE` 시가호, `SAN JOSE` 산호세.
   하이픈으로 이어진 이름도 붙여 쓴다: `FRANKFURT-MAIN` 프랑크푸르트, `FRANKFURT-ODER` 프랑크푸르트오데르.
5. 같은 이름이 여러 나라에 있어도(`SANTIAGO`, `COLUMBUS`) 한 가지로 적는다.

## 반드시 지킬 것 (검사에서 걸린다)

- `ko` 에는 **한글만** 쓴다. 로마자·한자·괄호·설명·큰따옴표(`"`)·탭·줄바꿈을 넣지 않는다. 숫자가 이름에 있으면 숫자는 그대로 둔다.
- `ko` 의 글자 수가 `en` 의 글자 수보다 **길면 안 된다**(게임이 원래 이름 길이만큼만 그린다). 음역은 거의 항상 더 짧다.
  넘으면 줄인다(예: `ULM` 은 `울름`).
- 이름이 아닌 것(자리표시 문자, 숫자뿐인 것)만 `"ko": ""` 로 둔다. 모르는 이름이라고 비우지 않는다 — 규칙 2 로 적는다.

## 확인

출력 파일을 쓴 뒤 저장소 루트(`E:\SR2030ToyBox`)에서 검사를 돌려 "문제 0건"이 될 때까지 고친다:

```
uv run srkit mt-check <청크.in.jsonl 의 절대 경로>
```
